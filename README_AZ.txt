PanelNext — sıfırdan yeni Android panel layihəsi

Bu layihə köhnə panel UI-sinin üzərindən dəyişdirilməyib.
Yeni package: com.ailenezareti.panelnext

Server API:
https://hesabat.site/usaq/webpanel/api

Əsas ekranlar:
1) Dashboard — xəritəsiz ağıllı GPS/zəng/batareya analizi
2) Xəritə — tam ekran OSM xəritəsi, qalın marşrut, sürətə görə rəng, A/S/dayanacaq/istiqamət markerləri, GPS 24s, Mən + Obyekt
3) Zənglər — axtarış və gələn/gedən/cavabsız filtr
4) Zonalar — zona siyahısı və yeni zona əlavə etmə
5) Bildirişlər — server alert-ləri
